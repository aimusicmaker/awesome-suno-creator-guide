# Fix the problem you can hear

[← Home](../README.md) · [Prompt guide](prompting.md)

These are suggested experiments, not verified fixes for every model. Save the take you like before replacing or extending anything.

| What you hear | First change to try | If that is not enough |
|:--|:--|:--|
| The instructions become lyrics | Move prose directions out of Lyrics; keep only words and simple section labels | Rewrite the instruction as one short Style sentence |
| Words race past | Shorten the longest lines | Try a less busy arrangement or a different take |
| The chorus feels flat | Make the verse sparse and add one layer in the chorus | Rewrite the hook so the central phrase is clearer |
| Everything sounds crowded | Keep two defining instruments and remove competing styles | Lower the music under the vocal in an editor if separate tracks are available |
| An instrumental has voices | Confirm Instrumental is on; clear Lyrics | Request instrumental explicitly; use exclusions if available |
| A name sounds wrong | Try an easy-to-read phonetic spelling in a small draft | Rewrite the surrounding line or record the name yourself |
| The intro takes too long | Ask for a short intro | Start your social edit at the chorus; exact timing needs editing |
| The ending cuts off | Request a resolved ending and allow room after the final lyric | Extend if your plan supports it, or fade at a musical boundary |
| A new version ruins a good chorus | Return to the saved take | Use section editing if available; compare the join before export |
| A “15-second” song is much longer | Treat 15 seconds as an editing target | Select a complete phrase and trim or fade in your editor |
| A background track fights narration | Lower the music volume first | Request fewer midrange instruments and no lead solo |
| A detector score looks surprising | Confirm the correct file was checked | Ask for production history; never use the score alone to accuse a creator |

## A simple stopping rule

Pick the one defect that prevents use. Compare the saved take with one changed version. If the change helps, keep it; if it doesn't, roll back. Set your own attempt limit before generating more.

## Fix a section without restarting

Use **Replace Section** for a weak passage, **Edit Lyrics** for a lyric correction, and **Extend** or **Quick Extend** for a continuation. Use **Crop** and fades for a short clip or clean ending. Save the original, then compare both sides of every edit. Controls depend on access and interface.
